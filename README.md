# wisamdamouny — CV & Portfolio

Personal brand, CV and portfolio site for **Wisam Damouny**.

Built as a hand-crafted, dependency-free static site (single `index.html`).
Uses [Inter](https://rsms.me/inter/) and supports a light/dark theme.

## Development

Open `index.html` directly in a browser, or serve it:

```bash
python3 -m http.server 8080
```

## Status

This repo is the **target repo** for ikando's human↔agent board loop. Board tasks from the
ikando instance drive work here: an agent claims a task, branches, implements, opens a PR,
and moves the card to **In Review** for human review.
